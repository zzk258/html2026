# 附件目录

日志里「附件」引用的文件都放在这里。两种放法，任选其一：

```
更新日志/files/
├── 拓扑图.pdf                ← 手动模式：直接放根目录，文件名唯一即可
├── 巡检报告.docx
└── <日志ID>/                 ← 自动写入模式：组件自己建子目录
    └── 出口改造配置.txt
```

- 组件只存文件名、大小、类型，文件本体不打包进 JSON；推送后线上打开日志即可下载
- **手动模式（最简单）**：把文件直接复制到本目录，文件名和编辑器里显示的一致即可，
  不用管日志 ID；不同日志用了同名文件就会指向同一份，注意别撞名
- **自动写入**：从 `启动本地预览.bat` 打开（localhost，需要 Node.js），
  编辑器里点「连接项目目录」选中本目录，之后选附件即自动写进 `<日志ID>/`，删日志时该目录自动清空
- 删除日志后的残留，跑 `更新日志/清理附件.ps1` 清理（默认只预览，`-Apply` 才删）

单个文件建议不超过 50MB（GitHub 单文件上限 100MB，仓库建议控制在 1GB 内）。
本 README 只是占位，让空目录能被 git 记录到。
